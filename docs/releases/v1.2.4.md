# FamiliarMac 1.2.4

Magic Mouse page navigation now follows finger movement continuously, with native Chrome overscroll feedback. Dock notification badges grow and move with their application icons.

- Page gestures support reversal and cancellation without duplicate Back/Forward shortcuts. Virtual pointer targeting follows the real cursor.
- Existing two-finger workspace gestures, double taps, pointer motion and physical clicking retain their behavior.
- Notification counts remain live while magnified, with correct stacking and cleanup.
- Includes FamiliarMac Magic Mouse 0.2.2 with upstream attribution and a pinned source revision.

Both changes were tested locally and confirmed by the user. Automated tests cover gesture routing, targeting and cancellation, and badge geometry/lifecycle.

Update from Settings → Dock & Window → Check for Updates. Existing preferences are preserved. Log out only when convenient if prompted to load updated desktop components. Machine-specific NVIDIA, Wi-Fi and boot changes remain outside the automatic update.
