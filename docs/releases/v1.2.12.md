# FamiliarMac 1.2.12

- Rebuild Apps proportions around the Tahoe reference: seven-column Grid, narrower List with five suggestions, left-aligned incomplete rows, and sizing from the actual available width. Category pills fit the Grid width; narrow layouts can scroll categories.
- Remember Grid/List selection, reveal keyboard-focused items, preserve search/menu keyboard navigation, and defer suggestion refresh while dragging an application.
- Match divider alignment and appearance. The search divider is permanent; the divider below categories appears only after scrolling. Scrollbars appear during interaction and fade without changing content width. Remove application hover backgrounds.
- Add general Mac-style keyboard mappings and guarded Files/Desktop shortcuts. See [keyboard behavior and limitations](../MAC-KEYBOARD.md).
- Avoid repeated unchanged rounding shader updates and remove unnecessary shadow effects when invisible. Rounded corners remain supported.

## Machine-specific work

Native compositor experiments and measured MacBook results are recorded separately
under `experimental/native-rounding` in the repository. They are excluded from the
release archive and automatic installation. Existing optional Chrome/Plex records
remain separate from general defaults. No device graphics profile is installed by
this release.

## Updating

Install directly from an earlier portable release; intermediate versions are not
required. Log out and back in after installation to load Shell changes. Existing
machine-specific Chrome/Plex settings are not changed.

## Validation

Regression coverage includes allocated-width layout, incomplete rows, focus and
menu navigation, deferred drag refresh, persistence, scrollbar lifecycle, Finder
focus/modifier guards, text deletion, desktop patching, rounding uniform caching,
and release package isolation. Apps layout was also measured in the live Shell at
200% scale. New keyboard actions have automated coverage; application-specific
behavior may differ as described in the keyboard guide.
