# FamiliarMac 1.1.1

Fixes portable updates on installations with managed boot/login appearance: the release now includes the login-layout helper required by that installer. Missing helpers are checked before any appearance files are changed.

Update from Settings → Dock & Window. After installation, log out and back in when convenient; the updater never logs you out automatically.

Hardware-specific NVIDIA/Nouveau, Wi-Fi, firmware and kernel repairs remain excluded. Existing desktop preferences are preserved.
