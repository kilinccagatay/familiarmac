# FamiliarMac 1.2.2

- Fix periodic Magic Mouse pointer stutter caused by opening and closing every input device during discovery. Filter devices before opening them and avoid rechecking unchanged unsupported devices.
- Recover workspace swipes when a Magic Mouse is powered off mid-gesture, even while its device nodes remain present.
- Start password entry by typing on the highlighted login account, preserving the first character, digits, spaces and Unicode text. Lock-screen behavior is unchanged.

All three fixes were confirmed on the physical test computer. Regression tests cover device filtering, swipe timeout recovery and native GJS character handling.

Existing mouse, gesture and keyboard preferences are preserved. Hardware-specific NVIDIA, Wi-Fi and boot repairs remain excluded from the portable update. The optional managed GDM login overlay is installed separately; the portable updater does not replace an existing system login layout.
