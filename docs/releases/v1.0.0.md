# FamiliarMac 1.0.0

First versioned portable release for Zorin OS 18.x, GNOME 46, x86-64.

- Mac-style panel, exported application menus and shortcut hints, Spotlight calculator, Dock and Finder integration.
- FamiliarMac Genie with minimized window previews and the system animation preference.
- Dock & Window in Settings, guided application menu checks, installed version and update controls.
- Grouped Wi-Fi networks, primary-route Ethernet indicator, fixed Finder/Apps positions and animated Dock reordering.
- Hardware-selected computer illustrations and icons, shared window controls, boot/login appearance in portable installation.

Download `familiarmac-1.0.0.tar.gz` and `SHA256SUMS` from this release, then:

```sh
sha256sum --check SHA256SUMS
tar -xzf familiarmac-1.0.0.tar.gz
cd familiarmac-1.0.0
./install.sh --all
```

Run as your desktop user. The installer requests administrator access for dependencies and shared visuals. Save work and log out/back in after installation; boot/login visuals can be checked on the next manual reboot.

NVIDIA drivers/firmware, Broadcom repairs, kernel/GRUB tuning, gmux brightness and reference-machine recovery fixes are NOT applied. These remain manual repository procedures. No automatic logout or reboot.

Updates appear in Settings → Dock & Window → FamiliarMac. Downloads are verified with the release checksum; installation requires confirmation. Preferences are preserved. Failed installations remain marked incomplete and never advance the installed version. This is not a transactional OS rollback; logs and the previous release are retained for recovery.

Known limits: applications without exported menus can require guided configuration; supported integration depends on toolkit and application version. The supported baseline is Zorin 18.x/GNOME 46, not arbitrary Linux desktops.
