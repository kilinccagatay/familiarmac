# FamiliarMac 1.2.0

## Magic Mouse and Mission Control

A connected Magic Mouse has dedicated Point & Click and More Gestures settings with animated demonstrations. Optional gestures open Mission Control, navigate pages, switch desktops and full-screen applications continuously, and toggle document zoom. The independent, attributed [familiarmac-magic-mouse 0.2.0](https://github.com/kilinccagatay/familiarmac-magic-mouse) library is bundled at a pinned commit.

Mission Control shortcuts support keyboard recording, the Apple keyboard key, configurable middle/back/forward mouse buttons, and three/four-finger trackpad gestures. New mouse gestures are opt-in. Existing keyd mappings are preserved.

Mission Control stays open during workspace swipes, uses separate compact and expanded desktop labels, identifies the active desktop and shows an empty-workspace message. Layout, startup, removed-desktop cleanup and empty-workspace focus handling are corrected. Hover outlines stay hidden until transitions finish.

## Bluetooth and Dock

Bluetooth has a dedicated menu-bar icon, device controls and battery information. Supported Magic Mouse devices get their own icon. Bluetooth visibility defaults on; its visibility setting and Wi-Fi visibility live in the corresponding system Settings panels. Connection preferences are preserved. Minimized-window Dock previews participate in magnification.

## Updates

Managed extension migrations survive preference restoration, including updates launched by older clients. Portable installation includes the mouse service, gesture library, settings demos and login-layout helper. NVIDIA/Nouveau, Broadcom, kernel and reference-machine boot repairs remain manual and excluded from portable releases.

## Validation and limits

The original Magic Mouse was tested locally for double-tap, navigation, document zoom and continuous workspace switching. Lightning and USB-C models have parser coverage, not physical validation. Smart Zoom uses supported apps’ zoom commands; it is not macOS content-aware framing. The gesture library never injects input itself.

Log out and back in after updating to load the new Shell modules. The updater offers logout without forcing it. Automated checks and local-session tests do not replace testing each hardware model; this release has not completed a fresh end-to-end VM upgrade through Settings.
