# FamiliarMac 1.1.0

## Mission Control and fullscreen spaces

Named desktops, an add-desktop control, compact and expanded previews, and fullscreen application spaces make window switching more familiar. The foreground window receives emphasis. Window selection preserves native corners with a spaced blue outline. Opening an app from the Dock returns to the desktop.

Fullscreen applications receive their own space and return to their previous desktop when leaving fullscreen. The top edge reveals menus and window controls. Finder supports native toolbar reveal, Escape to leave fullscreen, and Alt-click for conventional maximization. Notification banners wait until Mission Control closes.

## Finder

A unified toolbar and a single expanding search field replace the duplicate search controls. Advanced preferences choose This Mac, Current Folder, or Previous Search Scope. Native search filters and file operations remain available.

## Installation and update

Install the portable bundle with `./install.sh --all`, or update from Settings → Dock & Window. Log out and back in after installation to load the new Shell code. No update initiates logout automatically.

Nautilus 46 is supported by the Finder adapter. A binary hash guard retains native behavior after unsupported updates until the adapter is rebuilt. Other toolkit title bars and secondary-monitor fullscreen behavior still need separate verification. Hover-transition refinements have been installed and tested, but prolonged visual validation remains ongoing. See [Finder and Spaces](../FINDER-AND-SPACES.md).

Hardware-specific NVIDIA/Nouveau, Wi-Fi, firmware, and boot/kernel repairs are excluded from the portable package and automatic update path.
