# FamiliarMac 1.2.9

Cmd+Q now uses a common desktop Quit dispatcher instead of assuming that every application implements Ctrl+Q. It activates the focused application's exported Quit/Exit command when available, preserving the application's own save prompts. Otherwise it requests normal window closure; applications that keep running in the tray may remain active. No process is force-killed. The binding is unavailable on the lock screen and ignores key repeat.

Chrome menu integration now honors an explicit absolute `--user-data-dir` in the Flatpak Chrome flags file. It configures the selected profile's system title bar while preserving graphics flags, personal settings and later user overrides. Separate profiles receive separate restore records; locked profiles are not edited.

Dock window-preview close controls keep their compact size and now use a more visible red background with a white cross.

## Updating

Install directly from any previous portable release; intermediate versions are not required. Log out and back in after installation to activate the common Quit binding and Shell changes. This release does not enable the device-specific Chrome graphics tuning or create/switch browser profiles.

## Validation

Regression tests cover exported and disabled Quit actions, focus changes, graceful fallback, explicit Chrome profile selection, running-profile protection, independent restore records and preservation of unrelated settings.
