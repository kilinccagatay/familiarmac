# FamiliarMac 1.2.13

- Fix Command-Backspace on desktop file selections. GNOME identifies desktop windows as `gjs` with a `Desktop Icons` title, so the application mapper now recognizes that combination as well as the desktop application ID.
- Selected desktop files move to Trash without Fn. Finder's working Command-Backspace behavior and other GJS applications' shortcuts remain unchanged.

## Updating

Install directly from an earlier portable release. Existing device-specific Chrome
and Plex settings are unchanged. Log out and back in after installing to load the
updated integrations.

## Validation

The actual keyd parser accepts the mappings. Regression checks cover desktop
windows on multiple monitors, the desktop application ID, Finder, unrelated GJS
windows and terminal shortcuts. The user verified Command-Backspace on both
Finder and the desktop before publication.
