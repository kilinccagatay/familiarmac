# FamiliarMac 1.2.7

The green window button now uses Remmina’s own fullscreen transition. This avoids the oversized VNC window produced by compositor-only fullscreen changes, which caused session crashes on the tested system. Entering and leaving fullscreen was tested locally and confirmed by the user.

The adapter targets the selected connection window without sending keyboard shortcuts to the remote computer. Other applications retain their existing fullscreen handling. Remmina currently uses its native window lifecycle rather than a separate FamiliarMac fullscreen Space.

Window rounding and shadows also skip oversized offscreen buffers to limit GPU memory allocations.

Update from Settings → Dock & Window → Check for Updates. Quit Remmina completely, including its tray process, and reopen it after the update to load the adapter. The standard packaged GTK3 Remmina launcher is supported; Flatpak and Snap builds are not covered. Existing connection profiles and preferences are preserved.
