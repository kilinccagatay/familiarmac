# FamiliarMac 1.2.6

Dragging an unopened pinned application out of the Dock no longer starts its launch bounce or temporarily keeps its icon visible after removal. Launch feedback now begins on a completed click, while native application startup feedback remains supported.

Regression tests cover drag/removal, context menus, completed clicks, native launch feedback and handler cleanup. The fix was tested locally and confirmed by the user.

Update from Settings → Dock & Window → Check for Updates. Existing preferences are preserved.
