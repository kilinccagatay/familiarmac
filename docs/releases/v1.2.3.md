# FamiliarMac 1.2.3

- Improve Magic Mouse click reliability, including Cancel buttons in system dialogs.
- Keep input processing responsive when login-session queries stall, and safely hand devices between button and gesture handling.
- Block streamed workspace gestures during system dialogs and recover cleanly when interrupted.
- Fix long Magic Mouse swipes wrapping or reversing unexpectedly.
- Keep wallpaper visible during desktop boundary bounce and move the menu bar with the desktop. Native workspace transitions now include the menu bar for both touchpad and Magic Mouse.

The mouse fixes and desktop transitions passed local regression tests and were confirmed by the user on the physical computer. Existing keyboard, mouse and gesture preferences are preserved. Hardware-specific NVIDIA, Wi-Fi and boot repairs remain excluded from portable updates.

After updating through Settings, sign out and back in when prompted to load the updated Shell components. Package-manager busy-state handling remains an open follow-up; this release does not claim to resolve it.
