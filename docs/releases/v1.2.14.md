# FamiliarMac 1.2.14

- Restore the native selected-day agenda below the calendar, including event names, times and opening the default calendar application.
- Keep calendar and notification sizes stable while the agenda grows. Add Today navigation, centered date headings and clearer current-month days.
- Center the empty-notification message and use normal text weight. Refine event cards and calendar button styling.
- Replace full-cell desktop selection with a separate rounded icon frame and blue filename caption. Remove hover highlighting and the drag destination overlay without changing file operations.
- Hide owned desktop windows from the application list earlier during login to prevent a transient generic Dock icon. Ordinary dialogs remain visible.

## Updating

Update directly from an earlier portable release; intermediate versions are not required.
Log out and back in after installation to load the desktop changes. Machine-specific
Chrome, Plex, drivers and boot settings are not part of this update.

## Validation

Regression tests cover desktop window ownership and lifecycle, installer source preservation,
calendar navigation, agenda restoration and popup sizing. Live measurements confirmed stable
calendar and notification heights across selected days. The desktop selection frame was rendered
with GTK; the user verified the drag destination overlay removal. Login captures compared the
transient Dock icon with and without early desktop hiding.
