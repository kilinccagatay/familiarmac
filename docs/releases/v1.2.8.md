# FamiliarMac 1.2.8

Settings → Dock & Window now has a separate refresh button for release checks. Download Update also checks the latest release before asking for confirmation, so an older offer cannot leave the panel stuck when a newer release appears. Failed checks and installations return to a retryable state.

Dock window-preview close buttons are smaller and more restrained. Window titles and actions in the Dock context menu share the same left alignment, reserving checkmark space only when needed.

## Updating

Release packages are complete: update directly from 1.2.5, 1.2.6 or 1.2.7 to 1.2.8; intermediate installations are unnecessary. Desktop preferences are preserved. Log out and back in after installation to load the new Shell code.

If an older Settings panel still offers a superseded release, close Settings completely and check again after refreshing its release cache with `python3 ~/.local/share/familiarmac/updater/release-update.py --check --force`. This checks metadata only; it does not install anything. The dedicated refresh control becomes available after installing 1.2.8.

Machine-specific Chrome playback notes remain opt-in documentation. This update does not apply their graphics or profile settings.

## Validation

Regression tests cover forced checks, busy-state protection, recovery from network/install failure, rejection of a superseded offer, direct upgrades across skipped releases, and Dock menu alignment with and without a focused window. The native GTK updater is exercised with a fake worker; these tests do not install software or alter host preferences.
