# FamiliarMac 1.2.11

- Command-Q uses the application's exported Quit action, including labels containing the application name and matching tray menu actions. Window closure is no longer used as a substitute for Quit. Menu loading has a bounded retry that cancels when focus changes; unavailable actions produce a notification. Command-W is unchanged.
- Tray activation tokens no longer start the Dock launch animation when choosing Quit. Actual application launches retain their animation.
- Dock & Window remains available in Settings and is hidden from the Apps launcher.
- Apps reserves the first suggestion for the newest installation only during its first ten minutes. Other slots use usage frequency; after expiry, the entire row uses usage frequency, including while the launcher is open.

## Updating

Install directly from any earlier portable release. Log out and back in after installation to load the Shell changes. Existing keyboard mappings and device-specific graphics settings are preserved.

## Validation

Regression coverage includes named and tray Quit actions, disabled and hidden actions, asynchronous menu readiness and focus changes, startup-token filtering, normal launch feedback, launcher visibility, and the ten-minute suggestion boundary.
