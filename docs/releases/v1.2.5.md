# FamiliarMac 1.2.5

Leaving full screen now reliably removes the temporary desktop after returning the window to its original desktop. Desktop icon surfaces no longer prevent cleanup while they follow the active workspace.

Real application windows and dialogs continue to keep their desktop intact. Regression tests cover repeated full-screen cycles, closing a full-screen window, and preserving dialogs. Four consecutive Finder full-screen cycles were also verified locally without increasing the desktop count.

Update from Settings → Dock & Window → Check for Updates. Existing preferences are preserved.
