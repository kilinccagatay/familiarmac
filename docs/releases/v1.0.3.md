# FamiliarMac 1.0.3

Dock icons now bounce while applications open, stopping when their window is ready.
Control this in **Settings → Dock & Window → Animate opening applications**.
The effect respects system animation preferences and preserves the existing
startup-completion and Dock refresh fixes.

Icons also refresh correctly after resolution or display-scale changes. Both
features are included in normal installations and updates.

Live validation covered Calculator launch feedback, stopping and restoring the
icon, the Settings toggle, and repeated display mode/scale changes. Automated
regression tests cover Dock behavior, settings and portable installation.

For other installations, save work and log out/in after updating to load Shell
changes. Updates never log out automatically. NVIDIA/Nouveau, Wi-Fi repairs and
reference-machine boot settings remain excluded from portable installation.
