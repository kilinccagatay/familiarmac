# FamiliarMac 1.0.1

This release improves Dock interaction and brings update controls into Settings.

## Dock and appearance

- Finder and Apps stay fixed; other favorites reorder with a full-width insertion gap and moving neighbors.
- Fix disappearing icons, duplicate drag previews, flicker and Trash visibility during reordering.
- Drag a favorite upward to Remove, or onto Trash to Remove from Dock, with sound feedback. This unpins the app; it never deletes it.
- Fix Options submenu highlighting and repeated Apps launcher clicks.
- Dock & Window adds size, auto-hide and magnification controls, with Small/Large labels and default stop marks.
- Magnification uses frame-clock animation, higher-resolution icon rendering, an expanding background, moving divider and pointed name bubbles.
- Edge pressure and show delay are removed; revealing the Dock magnifies the icon under the pointer while hidden Dock icons remain hidden.
- A stable vertical hover lane prevents icon movement during reveal from switching magnification on and off.
- Shared menu/GTK accent colors and neutral menu backgrounds are refined; the battery glyph has an internal charging bolt, white charging text and cutout text on neutral fill.

## Updates

Updates now stay inside **Settings → Dock & Window**:

- Check for Updates refreshes the status without opening another window.
- Only a newer version offers a Download & Install confirmation.
- Download progress appears below the version row; verification and installation follow automatically.
- Installation success offers Later or Log Out; no forced session closure.
- Concurrent background/manual checks use independent atomic cache writes.

The same portable installation boundaries apply: no NVIDIA/Nouveau firmware, drivers, Broadcom repairs, kernel/GRUB or reference-machine fixes. Fresh installation: verify SHA256SUMS, extract the bundle and run `./install.sh --all` as your desktop user. Existing 1.0.0 installations can update through Dock & Window; this release replaces its separate update window with inline controls.

## Validation

Automated checks cover Dock reordering, submenu focus, magnification geometry, visibility states, rendering lifecycle, updater/package integrity and portable installation boundaries. Recent hover-lane and battery refinements have passed targeted tests and rendered previews; final live-session visual confirmation remains pending. This release does not claim identical macOS animation on every GPU or scale factor.
