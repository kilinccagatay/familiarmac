# FamiliarMac 1.0.2

Ready application windows now recover from stale startup state without waiting
for the Dock icon to appear. The user confirmed the ChatGPT delay resolved on
the reference Mac after reloading the session.

## Dock and menus

- Complete only an unambiguous startup belonging to a focused, mapped normal X11 window of a STARTING application on GNOME before 49. Unrelated launches, splash windows, native Wayland clients and ambiguous matches are left alone.
- Track tray activation and refresh Dock state on map, window identity and taskbar changes without interfering with a drag transaction.
- Keep magnification while a context menu is open and position the menu above the visible icon, with a continuous background and soft rounded pointer.
- Show application names immediately; share rounded bubbles with Remove and Remove from Dock feedback.
- Align Options labels when a checkmark exists, without an empty checkmark gutter when nothing is selected.
- Switch status menus on the first click, including modal popup capture; retain click-only opening.
- Restore the transparent Notification Center outer surface in light and dark appearance.

## Settings

- Keep Dock & Window available through installed Settings panel shortcuts, including desktop Change Background. User-level overrides preserve launch arguments and support guarded restoration without editing system launchers.
- Remove the redundant dot above the magnification Small label while retaining the slider stop.

## Installation and validation

Update through Settings → Dock & Window, or verify SHA256SUMS, extract the release
bundle and run `./install.sh --all` as your desktop user. Save work and log out/in
after installation to load the Shell changes; no automatic logout is forced.

Automated regression checks cover startup guards, tray lifecycle, Dock refresh,
menu geometry, magnification, status-menu capture, launcher installation/restore
and package boundaries. The ChatGPT delay has user confirmation; this release
does not claim exhaustive visual validation across all applications and scales.

NVIDIA/Nouveau fixes, Broadcom/Wi-Fi repairs and reference-machine kernel/GRUB
changes remain manual and excluded from the portable automatic installation.
