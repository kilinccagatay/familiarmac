# FamiliarMac 1.2.10

Fix the Command-Q shortcut conflict with Zorin Dock: quitting the focused application no longer displays numbered Dock shortcuts. The keyd mapping and desktop Quit handler now use a separate accelerator; existing Dock shortcuts and other Command mappings remain unchanged.

The existing Quit behavior is preserved: use the application’s exported Quit action when available, otherwise request normal window closure without force-killing processes.

## Updating

Install directly from any previous portable release; intermediate releases are not required. Log out and back in after installation to load the updated desktop shortcut handler.

## Validation

The user confirmed locally that Command-Q closes the application and no Dock numbers appear. Regression tests verify the matching accelerator and keyd mapping, Quit dispatch, and preservation of existing keyboard shortcuts.
